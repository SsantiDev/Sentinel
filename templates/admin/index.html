SISTEMA ACTIVO

Sentinel Monitor

Sistema de monitoreo automático de servicios y APIs en tiempo real.

Cómo funciona
1
Registrar servicio
Ve a Infrastructure → Service models → Add. Ingresa nombre, URL y el intervalo de verificación en segundos.
Agregar servicio
2
Ping automático
Celery Beat ejecuta pings automáticos según el intervalo definido por servicio. El ciclo global corre cada 60 s. Ocurre en background sin intervención.
Worker activo
3
Ver resultados
En Check result models verás cada ping registrado: estado UP/DOWN, tiempo de respuesta ms y código HTTP.
Ver historial
4
Alertas
Si un servicio falla, Sentinel registra una alerta automáticamente. Visible en los logs del contenedor worker.
docker logs worker
API REST
Todos los endpoints requieren Authorization: Bearer <token>
MétodoEndpointDescripción
GET/api/v1/services/Lista todos los servicios registrados
POST/api/v1/services/Crea un nuevo servicio a monitorear
GET/api/v1/services/{id}/Detalle y estado actual de un servicio
POST/api/v1/services/{id}/ping/Dispara un ping manual inmediato
GET/api/v1/services/{id}/history/Historial de checks (últimos 50)
